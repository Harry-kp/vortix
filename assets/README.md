# Assets

The GIFs are recorded with [VHS](https://github.com/charmbracelet/vhs) from `tapes/`:
`vhs tapes/<name>.tape` writes `assets/<name>.gif`. Each tape's header lists what it needs
(a lab server and its profiles, both from `scripts/vpn-lab.sh ensure`).

`social-preview.jpg` is the repository's link preview (Settings → Social preview), 2560×1280 from a
`multi-connection.gif` frame; upload it again there after changing it.
